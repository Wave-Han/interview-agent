**端点契约(权威):**
- `GET /api/question?topic=jvm&wrong_only=false&exclude_ids=1,2` → 200 `{"question_id":1,"topic":"jvm","difficulty":2,"question":"..."}`;无题 → 200 `{"message":"no question available for topic 'x'"}`。
- `POST /api/grade` body `{"question_id":7,"answer":"..."}` → 200 `{"score":0.8,"feedback":"...","recorded":true}`;模型未落库 → 200 `{"recorded":false,"message":"判题未完成(模型未调用判分工具)"}`;question_id 不存在 → 404 `{"detail":"题目不存在: 7"}`;LLM 异常 → 502 `{"detail":"<中文原因>"}`。
- `POST /api/ask` body `{"query":"..."}` → 200 `{"answer":"...","recommend_question_id":29}`;索引空 → 200 `{"message":"向量索引为空,请先运行: python -m interview_agent index"}`;LLM 异常 → 502 同上。
- `GET /api/stats?topic=jvm` → 200 `{"attempts":5,"avg_score":0.62,"wrong_count":2}`。

grade 实现要点(每请求局部,无跨请求状态):`q = qrepo.get(question_id)`(None→404)→ `prev = arepo.max_attempt_id(question_id) or 0` → 局部 `messages=[{"role":"system","content":build_system_prompt()}]` → `registry = build_default_registry(qrepo, arepo)` → `run_agent(client, registry, "", build_rubric_message(q, answer), on_output=lambda s: None, max_tool_calls=6, force_first_tool="record_result", messages=messages)` → `new_max = arepo.max_attempt_id(question_id) or 0`;`new_max > prev` → `{"score": <latest attempt score>, "feedback": latest_feedback, "recorded": true}`(score 查询:`SELECT score FROM attempts WHERE id=?`,(new_max));否则 recorded:false。LLM 两类异常 → `HTTPException(502, str中文)`;`IndexEmptyError` → message 200。

package com.wavehan.agentweb.dto;
import com.fasterxml.jackson.annotation.JsonIgnoreProperties;
import com.fasterxml.jackson.annotation.JsonProperty;

@JsonIgnoreProperties(ignoreUnknown = true)

    Double score,
    String feedback,
    @JsonProperty("recorded") boolean recorded,

```java
// service/AiClientService.java
package com.wavehan.agentweb.service;
// imports omitted in plan: spring web.client.RestClient, jackson, @Service, @Value

@Service
public class AiClientService {
    private final RestClient rest;
    public AiClientService(@Value("${python-api.base-url}") String base) {
        this.rest = RestClient.builder().baseUrl(base).build();
    }
    public GradeResultDto grade(long questionId, String answer) {
        try {
            return rest.post().uri("/api/grade")
                .header("Content-Type", "application/json")
                .body(Map.of("question_id", questionId, "answer", answer))
                .retrieve().body(GradeResultDto.class);
        } catch (Exception e) {
            throw new AiServiceUnavailableException();
        }
    }
    // fetchQuestion/ask/stats 同构:GET 带 query param / POST body,catch Exception -> AiServiceUnavailableException
}
```

`application.yml`:`python-api.base-url: http://localhost:8000`、`server.port: 8080`。
